# Decision Log

## When to log a decision
Add a row whenever this repo does one of the following:
- Deviates from a default set in this template (e.g. drops a module,
  changes a governance rule, skips a workflow step for a specific module).
- Changes the pinned model or model-tiering policy in
  `prompts/master_prompt.md`.
- Makes an architecture, tooling, or storage choice that a later
  contributor would otherwise have to reverse-engineer from the code.
- Changes a governance rule in `docs/governance/` after initial setup.

Anyone can propose an entry via PR; `@product-team` and `@architects` (per
`CODEOWNERS`) must approve it before merge — the same as any other change
under `docs/decisions/`.
